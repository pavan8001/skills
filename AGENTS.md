
# Global coding Standards

1. **YAGNI**: Don't build it until you need it.
2. **DRY**: Extract patterns after second duplication, not before.
3. **Simple First**: Start with the simplest solution, then optimize.
4. **FAIL FAST**: Explict errors over implicit/silent failures.
5. **Semantic Naming**: Use semantic self documenting names for variables, functions, classes, etc.
6. **Delete Aggressively**: Delete code after it's no longer needed, less code = fewer bugs.
7. **Simplified Technical English**: Always reply in ASD-STE100 simplified technical englishi, unless explicitly requested otherwise.
